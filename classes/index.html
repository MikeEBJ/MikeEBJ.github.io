⚔️ Classes

Choose a specialisation that suits your playstyle.
Your class persists through relogs and server restarts.

📋

How to pick a class

Find Stan in-game and right-click him to open the class selector GUI. Choosing a class costs 30 XP — choose carefully, you're stuck with it.

✨

Enchanter

Master of mystical augmentation

Place Mythical Dust in the lapis slot of an enchanting table to roll custom enchantments instead of vanilla ones. Dust cost equals the enchantment level.

  • ✓ Access custom enchants via Mythical Dust in the lapis slot
  • ✓ Dust cost = enchantment level (1, 2, or 3)

Lumberjack

Feller of forests

Unlocks the Tree Feller enchantment, letting you fell entire trees in a single swing.

  • ✓ Can use the Tree Feller enchantment
⛏️

Miner

Delver of the deep

Wield the Mythical Pickaxe to harvest Mythical Dust from ores. Also required for the Vein Miner and Crusher enchantments to function.

  • ✓ Mythical Pickaxe drops Mythical Dust from ores
  • ✓ Required for Vein Miner enchantment
  • ✓ Required for Crusher enchantment
🔨

Blacksmith

Shaper of mythical arms

Forge mythical items at the smithing table. Non-Blacksmiths see the result slot rejected with a red message.

  • ✓ Forge mythical items at the smithing table
  • ✓ Example: Diamond Pickaxe + Mythical Tip → Mythical Pickaxe
