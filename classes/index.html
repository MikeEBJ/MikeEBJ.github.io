⚔️ Classes

Choose a specialisation that suits your playstyle.
You are unable to change classes for now, so choose wisely!

📋

How to pick a class

Find Bilbo in-game and right-click him to open the class selector GUI. Choosing a class costs 30 XP — choose carefully, you're stuck with it.

Changing classes will be a later weekly update.

✨

Enchanter

Master of enchantments

Using mythical dust Enchanters can roll custom enchantments instead of vanilla ones. Dust cost equals the enchantment level.

  • ✓ Able to roll enchantments above level 2
  • ✓ Access custom enchants via Mythical Dust in the lapis slot
  • ✓ Rolling enchants cost the same amount of XP as vanilla enchants.

Lumberjack

Feller of trees

Unlocks the One Chop Wonder enchantment, letting you fell entire trees in a single swing.

  • ✓ Can use the One Chop Wonder enchantment
  • ✓ Has a 20% higher sapling drop chance when harvesting leaves
⛏️

Miner

Mythical Dust enthusiast

Able to gain mythical dust from ores.

  • ✓ Can use the Shredder enchantment
  • ✓ Can use the Miners Instinct enchantment

Blacksmith

Exceptional smither

Forge mythical items at the smithing table.

  • ✓ Has no "Too Expensive!" cap
  • ✓ Can forge mythical dust onto a pickaxe
  • ✓ Can smith a mythical tip onto a pickaxe
  • ✓ Gets a 10% discount on enchantment costs
